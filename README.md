## Arquitectura monolítica vs. microservicios

**Arquitectura monolítica:** toda la aplicación
está en un único bloque de código que se programa, se prueba y se
despliega junto. 

**Microservicios:** la aplicación se divide en servicios pequeños e
independientes, cada uno con una función concreta.

## Diferencia entre Frontend y Backend

La principal diferencia entre ellos es que el Frontend es la parte visible de una aplicación,
es decir la parte que vemos al usar una aplicación,
y el Backend son los procesos y métodos que constituyen su correcto funcionamiento.
